# 🎵 Spotify Clone

A responsive **Spotify Clone** built to replicate the core music-streaming experience of Spotify. This project includes a modern UI for browsing songs, managing playlists, and playing music.



```md
![Home Page](./screenshots/home.png)
![Music Player](./screenshots/player.png)
```

## ✨ Features

* 🎧 Browse and play songs
* 🔍 Search for songs and artists
* 📂 Browse music categories
* ❤️ Like/favorite songs
* 🎵 Music player with play/pause controls
* ⏭️ Next and previous song controls
* 🔊 Volume control
* 📱 Fully responsive design
* 🎨 Spotify-inspired modern UI
* 📋 Playlist management

## 🛠️ Tech Stack

* **Frontend:** React.js
* **Styling:** CSS / Tailwind CSS
* **JavaScript:** ES6+
* **Icons:** React Icons
* **API:** Music API / Custom Backend
* **Version Control:** Git & GitHub

## ⚙️ Installation & Setup

### 1. Clone the repository

```bash
git clone https://github.com/yourusername/spotify-clone.git
```

### 2. Navigate to the project

```bash
cd spotify-clone
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The application will run on the local development server provided by Vite.
